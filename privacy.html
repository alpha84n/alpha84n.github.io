Kazusa Media 개인정보처리방침

시행일: 2026년 11월 8일

1. 앱의 목적

Kazusa Media는 개발자 본인이 사용하는 개인용 미디어 앱입니다. 사용자가 허용한 Google Drive 파일을 조회하고 재생합니다.

2. 접근하는 정보와 이용 목적

폴더 탐색과 미디어 재생을 위해 Google Drive의 파일·폴더 이름, 식별자, 크기 등 메타데이터와 선택한 미디어·자막의 내용에 접근합니다. Drive 접근 권한은 읽기 전용이며 원본 파일을 수정하거나 삭제하지 않습니다.

3. 인증 및 저장

Google 인증과 토큰 관리는 실행 기기의 rclone이 담당합니다. 재생에 필요한 데이터는 실행 기기 또는 사용자가 운영하는 서버에서 처리되며, 미디어 캐시와 재생·학습 기록 등이 해당 환경에 저장될 수 있습니다. 이 안내 웹사이트는 Google 인증 토큰이나 Drive 파일을 수집하지 않습니다.

4. 정보 공유

Google Drive에서 얻은 정보는 미디어 조회·재생 기능을 제공하는 데 사용하며, 광고 목적으로 이용하거나 판매하지 않습니다.

5. 보관 및 삭제

인증 정보는 rclone 설정에, 캐시와 이용 기록은 앱의 저장 공간에 각각 보관될 수 있습니다. 사용자는 해당 저장 데이터를 삭제할 수 있습니다. Google 계정의 연결된 앱 관리에서 접근 권한을 철회할 수 있으며, 권한 철회만으로 기기에 이미 저장된 캐시나 기록이 삭제되지는 않습니다.

6. 웹사이트 호스팅

이 안내 사이트는 GitHub Pages로 제공됩니다. 사이트 접속 시 호스팅 제공자가 서비스 운영에 필요한 접속 정보를 처리할 수 있으며, 해당 처리는 GitHub 개인정보처리방침을 따릅니다.
